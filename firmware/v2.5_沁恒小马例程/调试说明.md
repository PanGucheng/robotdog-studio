# CH32V203 RobotDog 调试说明

本文用于当前四足机器人工程的烧录、联调与串口调试。

## 1. 当前可用的调试口

- 主命令串口：`USART3`，`PB10/PB11`，`115200 8N1`
- 串口烧录预留口：`USART1`，`PA9/PA10`，`115200 8N1`
- 现阶段固件里，`USART1` 只完成了引脚和外设初始化，**未实现真正的串口 IAP/Bootloader**
- 显示接口：`SSD1306 OLED`，`PB6/PB7` 硬件 `I2C1`，每秒刷新一次
- 状态指示：`PB8`，低电平点亮 LED，亮 0.5 秒、灭 0.5 秒

## 2. 推荐烧录方式：SWD 烧录

1. 用 WCH-LinkE 连接板子的 SWD。
2. 先编译工程，生成 `RobotDog.elf` / `RobotDog.hex`。
3. 通过调试器直接下载。
4. 上电后进入运行状态，再用 `USART3` 做联调。

## 3. 上电后观察点

- 默认应保持静止
- `PB8` 状态 LED 应以 1 Hz 闪烁
- OLED 上电后应显示运行状态页
- 蜂鸣器接 `PA8 / TIM1_CH1`；按键按下并稳定抬起后应鸣叫 0.5 秒
- 四个腿部舵机仅占用 `TIM3 CH1~CH4`

## 4. 串口联调方法

用 USB-TTL 接 `USART3(PB10/PB11)`，发送协议行，行尾带 `CRLF`。

常用命令：

- `@RDS1 REQ 1 HELLO`
- `@RDS1 REQ 2 STATUS`
- `@RDS1 REQ 3 PING`
- `@RDS1 REQ 4 STOP`
- `@RDS1 REQ 5 ACTION walk strength=18 lease_ms=500`
- `@RDS1 REQ 6 MODE auto`
- `@RDS1 REQ 7 CCD ON rate_hz=5`
- `@RDS1 REQ 8 CCD OFF`

说明：

- 释放版不启用旧的文本串口命令
- 主串口是命令和回传共用口
- 如果收到 `ERR`，先看命令格式，再看串口是否丢字节

## 5. 现场排查顺序

1. 先确认供电正常。
2. 看 `PB8` 状态 LED 是否处于熄灭状态。
3. 看 OLED 是否正常显示运行状态。
4. 看 `USART3` 是否能回 `HELLO` / `STATUS`。
5. 如果舵机异常，先检查 `PA6/PA7/PB0/PB1` 四路是否都有 PWM。
6. 如果蜂鸣器、OLED 或状态灯异常，检查 `PA8`、`PB6/PB7`、`PB8` 的初始化是否正确。

## 6. 注意事项

- `PB3` 被 CCD 时钟占用，如果板子上还保留 JTAG，请确保已关闭 JTAG、保留 SWD。
- `USART1` 目前是预留烧录口，不要把它当成已可用的在线升级通道。
- 若要做串口调试记录，优先抓 `USART3`，因为它承载主协议。
- OLED 使用硬件 `I2C1`，7 位地址为 `0x3C`（总线写地址 `0x78`）；如果屏幕不亮，优先检查上拉、电源和地址配置。
