# 1.2.2 发布范围与验收记录

日期：2026-10-21。本批软件发布范围为 `mcu-foundations` 与 `ti-mspm0-foundations`，修复公共代码编辑器的外部 CDN 加载依赖，以及 TI MSPM0G3507 CRC 校验工作区地址。课程、模板和 Firmware Baseline 不重新发布；Fun 不加入本批软件更新清单。

维护者明确要求：“不要匿名下载校验什么乱七八糟的，直接推新版就好了”。据此，本批跳过发布端完整匿名下载安装包的校验，以及独立 App Update Live Test 的整包下载。这是本批明确授权的例外，不修改常规发布脚本的默认校验规则，也不把未执行的项目记录为通过。

本地安装包大小、SHA-256、同一干净源码提交及打包来源记录仍须检查；正式固件门禁和打包资源检查保留。安装包全部上传登记成功后再更新清单，更新清单保留 Edition 隔离并进行小型 JSON 读回。发布凭据不进入客户端或清单。

发布进行中。最终产物来源、大小、摘要、Release 地址及已完成检查将在发布后补充；真实 NSIS 安装升级与数据保留验收未执行。本轮未重新烧录开发板，TI 修复的硬件证据为维护者允许的现有 Flash 读回和只读校验，详见 [TI 校验修复记录](../firmware/ti-flash-verify-fix.md)。
