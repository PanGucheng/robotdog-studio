# RobotDog Studio 单片机讲义系统人工复核清单

日期：2026-08-10

范围：开发模式中的前两节无硬件课。使用 `start-mcu-dev.cmd` 或 `corepack pnpm dev:mcu`，不需要安装或解包。

## 自动化基线

- `corepack pnpm typecheck`
- `corepack pnpm courses:validate`
- `corepack pnpm test`
- `corepack pnpm smoke:electron:mcu`

打包资源检查已经写入发布脚本，但按项目约定，本轮未执行打包。

## 人工流程

1. 打开单片机入门版，进入“认识 Studio 与第一次编译”的已有或新练习。
2. 确认左侧完整工程树和中央代码始终存在；右侧“课程”中可以切换“任务 / 讲义”。
3. 在任务页分别点击“阅读相关讲义”和“定位代码”：前者只改变右侧内容，后者只定位中央代码并展开左侧父目录。
4. 在讲义页切换章节、上一节/下一节，滚动后离开再返回；确认同一讲义版本恢复章节和位置。
5. 开启“专注阅读”，确认讲义自适应变宽，但 Monaco 没有卸载；退出后原文件、光标和未保存草稿仍在。
6. 点击讲义中的代码定位与任务定位；确认代码定位会展开工程树，任务定位只返回并突出对应步骤。
7. 在绑定的讲义章节点击“完成本节阅读”；确认任务状态同步。确认任务列表中的该步骤不能直接勾选。
8. 选中一段普通讲义文字，输入问题并点击“询问 AI”；确认自动进入 AI 助教，回答不产生候选、Diff 或“检查未通过”。
9. 断网后重新打开讲义，确认正文仍可读；本地图片若存在应通过受控资源接口显示，外部 HTTPS 链接需由系统浏览器打开。
10. 分别以 100%、125%、150% 缩放和窄窗口检查：讲义可滚动、章节选择和底部按钮可用，代码主体不出现不可恢复的挤压。
11. 打开一个 v2 旧练习（若本机已有），确认显示“最新版讲义 · 仅供参考”，且讲义不能改变旧练习的完成规则。
12. 课程目录中确认第三课仍为 `draft + pending-hardware-check`：开发模式只能查看说明、不能创建；正式发行仍不得显示。

## 通过标准

- 讲义问题不会让代码工作流进入失败候选；
- Renderer 中没有原始 Markdown 二次解析或真实 Asset 路径输入；
- 课程、代码、构建在单课讲义损坏时仍可使用；
- 未经真机验证的硬件内容没有被标记为完成或发布。
