## 1. 硬件平台与引脚分配

RoboHorse 机器马主控板采用沁恒 CH32V203C8T6 芯片。外设引脚分配经真机测试确认如下：

| 功能模块 | 引脚 | 外设 / 模式 | 硬件特性与说明 |
| --- | --- | --- | --- |
| **右前腿 A (CH2)** | PB0 | TIM3_CH3 PWM | 50 Hz 周期，正常方向脉宽 |
| **右后腿 B (CH3)** | PB1 | TIM3_CH4 PWM | 50 Hz 周期，正常方向脉宽 |
| **左前腿 C (CH0)** | PA6 | TIM3_CH1 PWM | 50 Hz 周期，软件方向反转 |
| **左后腿 D (CH1)** | PA7 | TIM3_CH2 PWM | 50 Hz 周期，软件方向反转 |
| **无源蜂鸣器** | PA8 | TIM1_CH1 PWM | 2 kHz 提示音，按键抬起后鸣响 0.5 s |
| **急停 / 模式按键** | PA1 | 上拉输入 | 低电平按下，20 ms 软件消抖，按下停机 |
| **CCD 移位脉冲 (SI)** | PA2 | GPIO 推挽输出 | 128 点线阵 CCD 启动脉冲 |
| **CCD 模拟输出 (AO)** | PA4 | ADC1_IN4 | 模拟电压采样，采集线阵灰度 |
| **CCD 时钟 (CLK)** | PB3 | GPIO 推挽输出 | 移位时钟（已释放 JTAG，保留 SWD 调试） |
| **OLED SCL** | PB6 | I2C1_SCL 复用开漏 | 需硬件上拉，SSD1306 屏幕（地址 0x3C） |
| **OLED SDA** | PB7 | I2C1_SDA 复用开漏 | 需硬件上拉，SSD1306 屏幕（地址 0x3C） |
| **板载状态 LED** | PB8 | GPIO 推挽输出 | 低电平点亮，心跳闪烁（周期 1 s） |
| **运行态通信串口** | PB10/PB11 | USART3 (TX/RX) | 115200 8N1，RDS1 协议与 CCD 数据回传 |
| **预留 IAP / 烧录串口** | PA9/PA10 | USART1 (TX/RX) | 115200 8N1，预留板载 USB-TTL 下载通道 |
| **SWD 调试与下载** | PA13/PA14 | SWDIO / SWCLK | WCH-LinkE 下载与救砖接口 |

## 2. 两套固件基线体系

仓库在 `firmware/` 下维护了两套基线，详见 [firmware/README.md](../../firmware/README.md)：

### 2.1 教学基线 (`firmware/ch32v203-baseline`)
- **适用场景**：大学单片机入门版（`mcu-foundations`）课次实验；
- **设计原则**：清晰分层（Driver / Board / App），外设默认保持静止（Opt-in），不自动初始化舵机运动或蜂鸣器，为学生提供纯净的裸机与 HAL 学习环境；
- **构建入口**：
  ```powershell
  $env:RHS_TOOLCHAIN_ROOT = (Resolve-Path "vendor/wch/Toolchain/RISC-V Embedded GCC12").Path
  cmake --preset wch-gcc12 -S firmware/ch32v203-baseline
  cmake --build firmware/ch32v203-baseline/build/release
  ```

### 2.2 小马全功能基线 (`firmware/v2.5_沁恒小马例程`)
- **适用场景**：自由练习沙盒（MCU Sandbox）以及小马巡线联调；
- **设计原则**：完整包含四足步态逆解计算、CCD 寻线滤波、RDS1 串口调试与 OLED 状态显示；
- **受控编辑边界**：学生代码集中在 `User/experiment.c`，核心逻辑与中断安全由 `User/student_control.h` 和下位机安全状态机守护。

## 3. 本地编译与工具链

上位机在 `vendor/wch/` 中内置了专用的免安装交叉编译工具链：
- **GCC**：`vendor/wch/Toolchain/RISC-V Embedded GCC12/bin/riscv-wch-elf-gcc.exe`
- **OpenOCD**：`vendor/wch/OpenOCD/OpenOCD/bin/openocd.exe`

在上位机执行 Candidate 编译或全量固件构建时，Main 进程会自动设置环境变量并调用构建服务，生成 `.elf`、`.bin`、`.hex` 及 `.map` 产物。

## 4. 烧录与调试流程

### 4.1 WCH-Link 烧录
1. 将 WCH-Link 调试器的 SWDIO、SWCLK、GND、3V3 连接至机器马主控板对应引脚；
2. 确保已安装 WCH 官方驱动（通过 NSIS 安装包自动安装，或使用设备管理器确认出现 WCH-Link 设备）；
3. 在上位机点击“一键烧录”或进入 WCH-Link 维护页面执行下载。

### 4.2 串口监控与 CCD 调试
连接蓝牙或 USB 转串口后，上位机通过 USART3（115200 8N1）与小马进行通信：
- 接收心跳状态帧与日志；
- 高频采样 128 点 CCD 数据，并在上位机绘图控件中实时渲染灰度曲线；
- 下发手动遥控指令或进入自动巡线模式。通信帧格式遵循 [RDS1 协议](./protocols/serial-v1.md)。
