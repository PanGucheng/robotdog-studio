# 单片机课程框架第一批切片人工复核清单

更新日期：2026-08-06

本清单只验证实际界面点击和可读性。课程资源、类型检查、自动化测试、构建与 Electron 冒烟已由开发侧完成。

## 启动方式

1. 关闭正在运行的 RobotDog Studio。
2. 在工程根目录双击 `start-mcu-dev.cmd`。
3. 等待单片机入门版窗口出现；开发服务会直接读取当前源码，无需打包或安装。

如果启动失败，请保留命令窗口最后一屏输出。正常流程不要求保存日志或截图。

## 必查项目

### 1. 默认入口

- 顶部应显示“RobotDog Studio 单片机入门版”。
- 右侧工作台第一个标签应为“课程中心”，并默认选中。
- 页面应显示“CH32V203 单片机入门”、课程对象、3 个课次和目标平台。
- 页面不应出现横向溢出、文字遮挡或空白整页。

### 2. 课次切换

依次点击左侧三个课次，确认右侧内容同步变化：

- 01：认识 Studio 与第一次编译；
- 02：源文件、头文件与函数，并显示建议先完成第一课；
- 03：第一个硬件实验（待定）。

被选中的课次应有黄色圆形编号和白色卡片背景；连续快速切换不应失效或跳回第一课。

### 3. 硬件课提示

选择第三课后应同时看到：

- “需要开发板”和“待验证”标签；
- “本课尚未通过真机检查”警告；
- 明确提示不要据此接线或烧录；
- “开始学习（下一阶段）”按钮不可点击。

本轮不要执行任何真实接线或烧录。

### 4. 现有功能回归

- 点击“工程代码”，确认左侧源文件、头文件和只读文件仍可分别切换。
- 点击“编译与问题”“修改确认”“烧录与运行”“程序资源”“设置”，确认标签均可打开。
- 再返回“课程中心”，确认课次列表仍可点击。

### 5. 窗口与缩放

- 在默认窗口大小下检查完整布局。
- 在“设置”中至少切换一次 125% 或 150% 缩放，再返回课程中心。
- 允许课次详情区域纵向滚动；关键按钮和课次列表不应被永久遮住。

## 可选的趣味版隔离回归

关闭单片机版后，在工程根目录终端运行：

```powershell
npm run dev:fun
```

趣味巡线版不应出现“课程中心”标签，原“操作示范”和巡线工作台保持可用。

## 反馈格式

如果全部通过，只需回复“第一批课程界面人工复核通过”。

如果发现问题，请提供：

- 发生问题的课次或标签；
- 实际看到的现象；
- 复现步骤；
- 一张问题区域截图；
- 若应用报错或白屏，再附命令窗口最后一屏输出。
