## 软件流程

从沁恒版首页进入课程中心，打开第一课讲义；左侧目录跳转、讲义末尾开始实验、独立工程创建正常。工作台选中 `App/Src/experiment.c`，任务的“定位对象”定位第 5 行。阅读确认前两步，再修改参数。

`500U → 1000U`：真实 GUI 编辑后观察到“有未保存修改”和编译禁用；随后自动保存成功，文件落盘与工作区检查点一致。完整构建通过，任务记录前 6 步完成，停在第 7 步写入开发板。

`1000U → 100U`：通过 Ctrl+S 保存成功，底部显示“代码已变化，需要重新编译”。再次编译成功；两次本地构建证明分别绑定不同源码检查点和输入哈希，均生成 ELF / HEX / BIN / MAP，Flash 3692 字节、静态 RAM 2080 字节（不含运行时栈）。这些结果不能证明 LED 的实物现象。

AI 助教“问 AI”入口可预填问题；窗口移动和收起正常。输入“1000U 中的 U 是什么意思，为什么一轮约 2 秒，只解释不修改代码”，通过 Enter 发送并得到实际回答：区分当前工程的 500U 和提问中的 1000U，解释无符号后缀、两次翻转组成完整周期，并提示编译、烧录与真实观察是独立证据。最终显示“没有需要应用的新修改”，工程代码未被修改；不读取或记录 Key。

最终 v14 从讲义末尾“切换实验 → 新建一次实验”创建第 2 次独立工程，模板仍为 500U，绑定 `content-v14`，默认程序完整构建通过。旧实验与 v13 阅读记录保留；新版阅读页没有同版本指纹冲突。知识参考可按标题定位修改章节，代码步骤图在专注阅读中正常显示。
