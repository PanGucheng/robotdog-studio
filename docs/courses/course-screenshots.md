# 课程真实界面截图与清晰度验收

适用于 Studio、TI SysConfig 及其他软件的操作教程。学生需要按实际界面找到按钮和字段，操作截图应来自真实软件与本课工程；示意图可以说明概念，不能替代操作截图。

## 采集与裁切

1. 使用本课工程的独立副本完成操作，记录软件版本、工程来源和截图对应步骤。保存前后状态要与讲义文字一致。
2. 优先采集屏幕或窗口的原始像素，使用无损 PNG。先核对接口返回的实际编码和像素尺寸，不能仅凭文件扩展名判断。若接口只返回压缩或缩小过的 JPEG，先寻找可用的无损采集方式；采集条件达不到要求时，明确说明限制，不把低清预览当成高清原图。
3. 在软件中适当放大界面文字，再采集。Windows 的 175% 缩放只表示界面缩放，不能证明截图保留了屏幕原始分辨率。
4. 裁切无关区域，保留按钮、字段名称、选择值和足够的上下文。裁切保持原始像素；不要靠插值放大、锐化或 AI 重绘补救文字。JPEG 转存 PNG 只能避免后续有损压缩，不能恢复已经丢失的细节。
5. 不必每张图都画箭头。按学生理解需要选用分步局部截图、编号或文字说明。若加标注，不能盖住真实控件；使用 draw.io 绘图时按已安装 DrawIO skill 直接编辑 `.drawio` 文件。
6. 等界面和菜单稳定后截图，避开动画、工具提示遮挡、鼠标光晕及未完成操作。屏幕锁定时停止操作，提示用户解锁。

## 必须分别检查两种显示

- **原图 100% 查看**：按钮和字段文字边缘清楚，无明显压缩块、重影或断笔；字段值能直接辨认。检查像素尺寸与实际编码，PNG 后缀不代表来源无损。
- **讲义中的实际显示**：在课程阅读页和工作台讲义中检查图片。字体不能因为整窗截图缩到窄栏而过小，也不能把小图拉大后假称高清。优先拆成局部步骤图；可提供点击原图查看，但放大功能不能弥补采集质量。

验收时同时查看原图与最终页面，记录采用的系统缩放、截图像素尺寸、采集编码以及是否裁切或重采。任何一处学生需要猜字或猜操作目标，都应重采或调整讲义布局。

## 重新采集的执行方式（2026-10-14）

TI 第一课现已替换上述六张旧图，并补充课程入口、讲义、工作台、AI 助教和代码修改截图，共 15 张标注图。旧图保留在历史制作材料中，当前讲义不再引用。

1. 用 Computer Use 的 `sky` API 操作真实窗口并最大化，先在界面内放大文字。截图预览只用于定位操作，不作为交付原图。
2. 用同一 API 向目标窗口发送 `Alt_L+Print`，把当前窗口原始位图复制到 Windows 剪贴板。
3. 在复制完成后，用 [save-course-window-capture.ps1](../../scripts/save-course-window-capture.ps1) 读取剪贴板位图并保存 PNG。该脚本只提取已复制的图片，不控制窗口。必须核对输出像素尺寸；本轮最大化窗口原图为 2560 × 1528，早期首页图为 1920 × 1008。
4. 用 [annotate-ti-first-lesson.py](../../scripts/annotate-ti-first-lesson.py) 按原始物理像素裁切，并直接生成原生 `.drawio` 文件。截图不重采样，标题、图框、编号和说明文字为独立可编辑对象。保留源文件与 [采集清单](./assets/ti-first-lesson-v3/capture-manifest.json)。
5. 本机可用 draw.io CLI 为 `D:\Program Files\draw.io\draw.io.exe`；WindowsApps 下的同名启动项不能完成本轮导出。使用实际 CLI 导出后检查文件是否存在、尺寸和修改时间，再检查视觉结果。

工作台与代码图按用户调大后的界面缩放再次采集，SysConfig 在最大化窗口内放大三个级别。总览用于编号定位，步骤图保留左侧导航和当前配置区，关键字段与说明在讲义宽度下可读。分别在课程阅读页、工作台知识参考及点击原图后验证。系统缩放不代替这三处显示验收；下次采集仍应以实际可读性决定放大级别。
