实板测试由维护者完成并直接确认，Agent 没有连接、烧录或运行实板；没有补造详细接线、逐项测量或实际测试日期。课程仍保留 `author-approved`，不将固件确认扩写成所有课程步骤已由 Agent 复验。本次未进行 NSIS 安装、升级和数据保留验收。

三个工程均已进入发布准备范围，维护者确认后正式基线门禁已通过。待发布软件版本设为 1.2.1，并准备 `docs/releases/1.2.1.md`；实际发布仍须先完成变更与提交，再从同一干净提交构建正式包。软件与课程更新仍独立，本批 TI 内容最低兼容软件版本为 1.2.1，以确保使用修正后的自由工程资源入口。本地 Gitee 分发仓库 `D:/RobotDog/robohorse-courses` 的 TI 同步脚本已经改为调用 Studio 的正式快照导出器，确保草稿过滤、明确授权校验和两套自由工程收录一致；仅准备脚本和说明，未运行实际打包或修改线上清单。上传后先匿名下载核对摘要再更新清单。
